🎯 Synthèse d'aide à la décision pour la soutenance :
Les données collectées confirment une forte hétérogénéité pédologique en Côte d'Ivoire. Sur les parcelles de transition (Yamoussoukro), plus de 60% des relevés mettent en évidence une acidité limitante ($pH < 5.8$) nécessitant un chaulage pour le maïs et la tomate, tandis que les bas-fonds présentent une humidité idéale pour le riz pluvial mais asphyxiante pour les tubercules.
